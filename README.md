# Chasidus — אנציקלופדיה של החסידות

An encyclopedia of Hasidism: every Rebbe a page, every dynasty a tree,
every town on a map — all linked to one another.

**Live site:** https://meoga.github.io/chasidus/

## What is here

- **3,246 Rebbe pages** — biography, teachings, teachers, students, sources.
  Pages that have not yet been proofread carry the note
  "ערך זה טרם עבר הגהה — ייתכנו בו טעויות" (this entry has not yet been
  proofread — it may contain errors). Rewritten entries are marked proofread.
- **126 dynasties** — each with its family tree.
- **1,091 towns** — where the Rebbes lived and taught, shown on a map
  with four eras: 1750, 1914, 1938, today.
- **988 timeline events.**
- **4,470 pages in all**, in Hebrew (right-to-left), with an English menu
  toggle (עב/EN) in the header. Article content stays Hebrew.

## Sources

Entries are built from many sources and cite them on the page — among
others Alfasi's *תורת החסידות*, Wodziński's *Historical Atlas of Hasidism*,
*Encyclopedia Judaica*, Hebrew and Yiddish Wikipedia, and the
*Jewish History Soundbites* podcast. Where sources disagree, the page
says so instead of picking one quietly. No quote or story is invented.

## How the site is built

A static site, generated by `build.py` from the data in `data/`:

```
python3 build_site.py
```

- `data/rebbes.json`, `data/towns.json`, `data/dynasties.json`,
  `data/timeline.json`, `data/sources.json` — the content.
- `build.py` — the generator (pages, search index, Hebrew calendar,
  yahrtzeit index, map data).
- `site/` — the generated site, published to GitHub Pages.
  `site/README.md` is a copy of this file; the source lives here,
  at the project root, and `build.py` copies it into `site/` on
  every build.

Pictures on article pages can be clicked to zoom. The header also has
a dark-mode toggle; the choice is remembered.
